## О проекте

Проект выполнен в рамках дисциплины **«Компьютерная графика»** и реализует полный цикл построения и визуализации M-образов для трёхмерной фигуры, заданной неявной функцией:

```text
F(x, y, z)
```

Используется соглашение:

```text
F(x, y, z) > 0   — точка находится внутри тела
F(x, y, z) = 0   — точка находится на поверхности
F(x, y, z) < 0   — точка находится вне тела
```

Таким образом, сама поверхность определяется уравнением:

```text
F(x, y, z) = 0
```

Проект позволяет:

- задавать простые трёхмерные примитивы;
- составлять из них сложные фигуры при помощи R-функций;
- вычислять значения функции на регулярной трёхмерной сетке;
- находить ячейки, через которые проходит поверхность `F = 0`;
- вычислять расширенную нормаль `N = (n1, n2, n3, n4, n5)`;
- сохранять компоненты нормали в виде пяти M-образов;
- кодировать данные в 24-битные BMP-файлы;
- восстанавливать по M-образам положение поверхности;
- визуализировать полученную модель в интерактивном 3D-пространстве.

# Что такое M-образ в рамках проекта

Для каждой ячейки трёхмерной сетки вычисляется расширенная нормаль:

```text
N = (n1, n2, n3, n4, n5)
```

Каждая компонента сохраняется отдельно.

Поэтому одному слою пространства соответствуют пять изображений:

```text
M1 — значения n1
M2 — значения n2
M3 — значения n3
M4 — значения n4
M5 — значения n5
```

Например:

```text
1 (M1).bmp
1 (M2).bmp
1 (M3).bmp
1 (M4).bmp
1 (M5).bmp

2 (M1).bmp
2 (M2).bmp
...
```

Для каждого слоя по оси `Z` создаётся собственный набор M-образов.

При стандартном значении:

```python
nz = 256
```

генерируется пять изображений на каждый Z-слой.

# Неявное задание поверхности

Простейший пример — единичная сфера:

```python
def sphere(x, y, z):
    return 1.0 - x*x - y*y - z*z
```

Её поверхность соответствует:

```text
1 - x² - y² - z² = 0
```

или:

```text
x² + y² + z² = 1
```

При этом:

```text
F > 0 — внутри сферы
F = 0 — поверхность сферы
F < 0 — снаружи сферы
```

Такой подход позволяет работать с геометрией не как с набором полигонов, а как с математическим скалярным полем.

```text
F(x,y,z) = 1 - x² - y² - z²
```

```text
F(x,y,z) =
```

## Параболоид

```text

```

```text

```

## Цилиндр

```text
F(x,y,z) = 1 - x² - y²
```

Цилиндр ориентирован вдоль оси `Oz`.

# R-функции

Для создания сложных объектов в проекте используются **R-функции**.

Они позволяют выполнять аналоги логических операций над неявно заданными телами:

```text
AND → пересечение
OR  → объединение
NOT → инверсия
```

При этом результат снова остаётся функцией:

```text
F(x, y, z)
```

а не бинарной маской.

---

## Пересечение

Для `alpha = 0` используется:

```text
R∩(w1, w2) =
w1 + w2 - √(w1² + w2²)
```

Реализация:

```python
def r_intersection_alpha0(w1, w2):
    return w1 + w2 - math.sqrt(w1 * w1 + w2 * w2)
```

---

## Объединение

```text
R∪(w1, w2) =
w1 + w2 + √(w1² + w2²)
```

Реализация:

```python
def r_union_alpha0(w1, w2):
    return w1 + w2 + math.sqrt(w1 * w1 + w2 * w2)
```

---

## Инверсия

Логическая операция `NOT` реализуется сменой знака функции:

```text
¬F = -F
```

```python
def r_inversion(w):
    return -w
```

Это позволяет, например, вычитать одно тело из другого.

# Демонстрационная модель — свеча с подставкой

В качестве основной составной фигуры реализована **свеча с подставкой, углублением и фитилём**.

Она состоит из нескольких независимых примитивов:

```text
Подставка
     │
     ├── цилиндр большого радиуса
     │
     ▼
Тело свечи
     │
     ├── цилиндр меньшего радиуса
     │
     ▼
Верхнее углубление
     │
     ├── вычитаемый параболоид
     │
     ▼
Отверстие под фитиль
     │
     ├── вычитаемый цилиндр
     │
     ▼
Фитиль
     └── добавляемый цилиндр
```

---

# Построение свечи через R-функции

Сначала объединяются подставка и основное тело:

```text
F_wax = F_base ∪ F_body
```

После этого из тела вычитается отверстие под фитиль:

```text
F = F_wax ∩ NOT(F_wick)
```

Затем вычитается углубление в верхней части:

```text
F = F ∩ NOT(F_dip)
```

После этого добавляется сам фитиль:

```text
F = F ∪ F_wick_stick
```

Общую структуру можно представить как:

```text
                     ┌──────────┐
                     │   Base   │
                     └────┬─────┘
                          │
                          │ UNION
                          │
                     ┌────▼─────┐
                     │   Body   │
                     └────┬─────┘
                          │
                          ▼
                         Wax
                          │
                ┌─────────┴─────────┐
                │                   │
             NOT Wick            NOT Dip
                │                   │
                └─────────┬─────────┘
                          │
                    INTERSECTION
                          │
                          ▼
                   Modified Wax
                          │
                          │ UNION
                          ▼
                     Wick Stick
                          │
                          ▼
                   Final Candle
```

# Генерация трёхмерного поля

Перед построением M-образов создаётся регулярная трёхмерная сетка.

Стандартная область:

```python
xmin, xmax = -2.0, 2.0
ymin, ymax = -2.0, 2.0
zmin, zmax = 0.0, 3.5
```

Размеры сетки:

```python
nx = 128
ny = 128
nz = 256
```

Шаг по каждой координате определяется как:

```text
dx = (xmax - xmin) / (nx - 1)
dy = (ymax - ymin) / (ny - 1)
dz = (zmax - zmin) / (nz - 1)
```

После этого для каждого узла вычисляется:

```text
u[k][i][j] = F(X[j], Y[i], Z[k])
```

Одновременно находятся:

```text
UMIN = min(F)
UMAX = max(F)
```

# Определение ячеек поверхности

Для каждой рассматриваемой ячейки берутся четыре точки:

```text
P1 = (x1, y1, z1, u1)
P2 = (x2, y2, z2, u2)
P3 = (x3, y3, z3, u3)
P4 = (x4, y4, z4, u4)
```

где:

```text
u = F(x, y, z)
```

Если все значения:

```text
u1, u2, u3, u4
```

положительные, то рассматриваемая область находится внутри тела.

Если все отрицательные — снаружи.

В обоих случаях ячейка пропускается.

Если знак меняется, считается, что через рассматриваемую область проходит поверхность:

```text
F(x, y, z) = 0
```

и для неё вычисляется нормаль.

---

# Вычисление расширенной нормали

Для обнаруженной поверхности вычисляется вектор:

```text
N = (n1, n2, n3, n4, n5)
```

Расчёт выполняется в пространстве:

```text
(x, y, z, u)
```

где:

```text
u = F(x, y, z)
```

Компоненты `n1..n5` вычисляются через определители по четырём точкам.

Эта математическая часть вынесена в:

```text
mimage_math.py
```

Основная функция:

```python
compute_n12345(...)
```

После вычисления выполняется нормализация:

```text
                 N
N_normalized = ─────
                |N|
```

то есть:

```text
√(n1² + n2² + n3² + n4² + n5²) = 1
```

---

# Кодирование нормалей в M-образы

После нормализации каждая компонента находится примерно в диапазоне:

```text
[-1; 1]
```

Для хранения используется 24-битный диапазон:

```text
0 ... 16 777 215
```

где:

```python
P_MAX = 256**3 - 1
```

Компонента нормали преобразуется по формуле:

```text
M = P_MAX × (1 + n) / 2
```

Таким образом:

```text
n = -1  → M ≈ 0
n =  0  → M ≈ P_MAX / 2
n =  1  → M ≈ P_MAX
```

После этого число разбивается на три компоненты:

```text
R
G
B
```

и сохраняется как пиксель BMP-файла.

---

# Структура одного набора M-образов

Для одной ячейки:

```text
N = (n1, n2, n3, n4, n5)
```

получаются пять значений:

```text
n1 → M1
n2 → M2
n3 → M3
n4 → M4
n5 → M5
```

То есть пять BMP-файлов работают синхронно.

```text
                Surface Cell

        ┌─────────────────────────┐
        │ N = n1 n2 n3 n4 n5     │
        └────────────┬────────────┘
                     │
        ┌────────────┼────────────┐
        │       │    │    │       │
        ▼       ▼    ▼    ▼       ▼
       n1      n2   n3   n4      n5
        │       │    │    │       │
        ▼       ▼    ▼    ▼       ▼
       M1      M2   M3   M4      M5
```

---

# Заголовок M-образа

Первая строка:

```text
y = 0
```

каждого BMP-файла зарезервирована под служебную информацию.

В первые девять пикселей записываются:

| Пиксель | Значение |
|---:|---|
| `0` | `SIZE_Z / nz` |
| `1` | `xmin` |
| `2` | `xmax` |
| `3` | `ymin` |
| `4` | `ymax` |
| `5` | `zmin` |
| `6` | `zmax` |
| `7` | `umin` |
| `8` | `umax` |

Таким образом, сами BMP-файлы содержат информацию, необходимую для последующего восстановления параметров пространства.

Визуализатору не требуется отдельно передавать:

```text
размер сетки
границы координат
диапазон F
```

он получает эти данные непосредственно из M-образа.

# Восстановление поверхности

За чтение M-образов и построение геометрии отвечает:

```text
Viz_pyvista.py
```

Визуализатор последовательно:

1. открывает один из M-образов;
2. читает заголовок;
3. получает размеры сетки и диапазоны координат;
4. загружает все пять M-образов каждого слоя;
5. декодирует RGB обратно в компоненты нормалей;
6. формирует массив:

```text
normals[k, i, j, m]
```

7. выделяет ячейки с ненулевой нормалью;
8. вычисляет координаты центров этих ячеек;
9. формирует облако точек;
10. передаёт его в PyVista.

---

# Построение облака точек

Для каждой ячейки вычисляется центр:

```text
x = xmin + (j + 0.5) × dx
y = ymin + (i + 0.5) × dy
z = zmin + (k + 0.5) × dz
```

Из пяти компонент для пространственного направления используются:

```text
n1
n2
n3
```

то есть:

```text
gradient = (n1, n2, n3)
```

Если длина этого вектора меньше заданного порога:

```python
magnitude_threshold = 0.05
```

ячейка отбрасывается.

Оставшиеся центры ячеек образуют облако точек поверхности.

# Настройка качества

Размер сетки можно изменить:

```python
start(
    candle,
    nx=256,
    ny=256,
    nz=512,
    zmin=0.0,
    zmax=3.5
)
```

Чем больше значения:

```text
nx
ny
nz
```

тем выше пространственное разрешение и тем точнее представляется поверхность.

Одновременно увеличиваются:

- время вычисления поля `F`;
- количество обрабатываемых ячеек;
- расход оперативной памяти;
- количество выходных данных.

# Создание сложных объектов

Простые фигуры можно комбинировать через R-функции.

Например, чтобы вырезать отверстие:

```python
def shape_with_hole(x, y, z):
    body = ...
    hole = ...

    return r_intersection_alpha0(
        body,
        r_inversion(hole)
    )
```

Для объединения:

```python
return r_union_alpha0(shape1, shape2)
```

Таким образом можно конструировать сложные объекты, сохраняя единое неявное описание:

```text
F(x, y, z)
```

# Основная идея проекта

Проект показывает один из способов перехода от математического описания трёхмерного объекта:

```text
F(x, y, z) = 0
```

к его дискретному графическому представлению:

```text
Mathematical Model
        │
        ▼
Implicit Function
        │
        ▼
3D Scalar Field
        │
        ▼
M-images
        │
        ▼
BMP representation
        │
        ▼
Surface reconstruction
        │
        ▼
3D Visualization
```

При этом сложная геометрия формируется не непосредственным редактированием полигональной сетки, а математическими операциями над функциями, описывающими отдельные геометрические тела.
