## Общее описание проекта

Этот проект реализует полный конвейер построения и визуализации **M‑образов** по неявной функции  
\(F(x, y, z)\), задающей трёхмерную фигуру.

Конвейер состоит из трёх крупных частей:

1. **Описание фигур** в виде функций `F(x, y, z)` и их композиция через R‑функции (`main.py`).
2. **Генерация M‑образов** — вычисление поля `F`, нормалей и сохранение пяти BMP‑карт (`mimage_generator.py` + вспомогательные модули).
3. **Визуализация** — чтение M‑образов, восстановление облака точек поверхности и интерактивный просмотр (`Viz_pyvista.py`).

Ниже подробно описано, за что отвечает каждый модуль и как они связаны между собой.

## Обзор файлов

### `main.py` — точка входа и описание фигур

Этот файл отвечает за **математическую часть**: здесь описываются функции `F(x, y, z)` для разных фигур и их комбинаций.

Содержимое:

- Примитивы:
  - `sphere(x, y, z)` — сфера радиуса 1 с центром в начале координат.
  - `ellipsoid(x, y, z)` — эллипсоид с полуосями `1.5, 1.0, 0.8`.
  - `paraboloid(x, y, z)` — параболоид вращения `z = x^2 + y^2`.
  - `cylinder(x, y, z)` — неограниченный цилиндр радиуса 1 вокруг оси `Oz`.

- Вспомогательные геометрические функции:
  - `_cyl_R(x, y, R)` — цилиндр произвольного радиуса `R`.
  - `_plane_z_ge(z, z0)` / `_plane_z_le(z, z1)` — полупространства `z ≥ z0` и `z ≤ z1`.
  - `_sphere_R_center_z(x, y, z, R, cz)` — сфера радиуса `R` с центром `(0, 0, cz)`.

- **Составная фигура «свеча с подставкой»**:
  - Набор параметров (радиусы, высоты) для подставки, тела свечи, углубления и фитиля.
  - Компоненты:
    - `candle_base` — широкая цилиндрическая подставка.
    - `candle_body` — цилиндрическое тело свечи.
    - `candle_wick` — отверстие под фитиль (вычитается из воска).
    - `candle_wick_stick` — сам фитиль‑палочка, который добавляется к воску.
    - `candle_dip` — углубление сверху (вогнутый параболоид).
    - `candle_wax` — объединение подставки и тела свечи.
  - Итоговая функция:
    - `candle(x, y, z)` — собирает свечу по схеме:
      \[
      F = \big(F_\text{w a x} \land \neg F_\text{wick} \land \neg F_\text{dip}\big) \lor F_\text{wick\_stick}
      \]
      Реализация делается через R‑функции `r_intersection_alpha0`, `r_union_alpha0`, `r_inversion`.

- Параметры области моделирования и сетки:
  - `xmin, xmax, ymin, ymax, zmin, zmax` — границы объёма.
  - `nx, ny, nz` — число узлов по осям.
  - `output_dir` — папка для сохранения M‑образов.

- Функция `start(F, ...)`:
  - Принимает одну функцию `F` или список функций.
  - Для каждой запускает `mimage_generator.generate_mimages(...)` с заданными параметрами.
  - Создаёт подпапки для разных фигур, если их несколько.

Использование:

- Для генерации свечи с подставкой:

```bash
python main.py
```

По умолчанию запускается `start(candle, zmin=0.0, zmax=3.5)`.

### `mimage_common.py` — общие константы и утилиты

Этот модуль хранит всё, что связано с **форматом хранения значений в BMP**:

- **Константы:**
  - `P_MAX` — максимальное 24‑битное значение цвета (`256^3 - 1`).
  - `HEADER_SHIFT` — сдвиг для параметров заголовка (чтобы отделить их диапазон от диапазона нормалей).

- **Работа с цветом:**
  - `encode_color_to_rgb(value)` — кодирует целое число в `(r, g, b)`.
  - `decode_rgb_to_color(r, g, b)` — обратное преобразование.

- **Работа с заголовком:**
  - `encode_header_param(param_value)` — кодирование параметра заголовка (int/float → RGB).
  - `decode_header_param(r, g, b)` — обратное преобразование RGB → значение параметра.

- **Работа с нормалями и значениями M‑образов:**
  - `normal_to_mimage_value(normal_component)` — из компоненты нормали в диапазоне `[-1, 1]` делает целое число `0..P_MAX`.
  - `mimage_value_to_normal(mimage_value)` — восстанавливает компоненту нормали из значения `0..P_MAX`.

Благодаря этому модулю все части проекта (генератор и визуализатор) используют **одинаковые формулы** и не расходятся в трактовке байтов BMP.

### `mimage_math.py` — математика для нормалей

Содержит чистые математические функции:

- `compute_n12345(...)` — по четырём точкам \((x_i, y_i, z_i, u_i)\) в 4D‑пространстве \((x, y, z, u=F)\) вычисляет пять коэффициентов нормали `n1..n5` к гиперплоскости, проходящей через эти точки. Формулы повторяют определители из методички.
- `normalize_n12345(n1, n2, n3, n4, n5)` — нормализует вектор нормали к единичной длине и возвращает `None`, если длина нулевая.

Эти функции **ничего не знают** о BMP, изображениях и т.п. Они используются только внутри генератора, когда нужно получить нормали для M‑образов.

---

### `mimage_header.py` — чтение и запись заголовка M‑образа

Модуль отвечает только за «шапку» в первой строке BMP:

- `read_header_from_mimage(path)`:
  - открывает любой из пяти M‑образов `Mi` (обычно `M1`);
  - считывает пиксели `[0..8, 0]` (9 чисел) и декодирует их в:
    - размеры сетки `nx, ny`;
    - количество слоёв `SIZE_Z`;
    - границы `xmin, xmax, ymin, ymax, zmin, zmax`;
    - диапазон значений `umin, umax`.

- `write_header_to_images(pix_list, nz, xmin, xmax, ymin, ymax, zmin, zmax, umin, umax)`:
  - получает список из пяти `pix` (по одному для каждого M‑образа);
  - формирует массив параметров заголовка;
  - записывает их в первую строку `y = 0` каждого изображения.

Вся остальная часть картинок (строки `y ≥ 1`) занята собственно значениями M‑образов — нормалями.

### `mimage_generator.py` — генерация M‑образов

Главный рабочий модуль, который из математической функции `F(x,y,z)` делает набор BMP‑файлов.

Основные функции:

#### `compute_function_field(F, xmin, xmax, ymin, ymax, zmin, zmax, nx, ny, nz)`

1. Строит одномерные массивы координат:
   - `X[j]` для `j = 0..nx-1`,
   - `Y[i]` для `i = 0..ny-1`,
   - `Z[k]` для `k = 0..nz-1`.
2. В цикле по всем узлам 3D‑сетки вычисляет `u[k][i][j] = F(X[j], Y[i], Z[k])`.
3. Одновременно находит `UMIN` и `UMAX` — минимум и максимум по всему объёму.
4. Возвращает:
   - `X, Y, Z` — координатные массивы;
   - `u` — трёхмерное поле значений функции;
   - `UMIN, UMAX` — диапазон `F`.

#### `generate_layer_mimages(k, X, Y, Z, u, nx, ny, nz)`

Генерация пяти M‑образов для одного слоя `k`:

1. Создаёт пять пустых изображений размера `(nx, ny)` для компонентов `n1..n5`.
2. Заполняет все пиксели (кроме строки `y=0`) «нулевой» нормалью — это фон для ячеек, где поверхность не проходит.
3. Обходит все ячейки в слое (`i = 0..ny-2`, `j = 0..nx-2`):
   - берёт четыре точки `P1..P4` и их значения `u1..u4`;
   - если все `u` одного знака — пропускает (поверхность F=0 в ячейку не заходит);
   - иначе вычисляет нормаль `n1..n5` с помощью `compute_n12345`;
   - нормализует её через `normalize_n12345`;
   - каждую компоненту `n_m` кодирует в палитру через `normal_to_mimage_value` и `encode_color_to_rgb` и записывает в соответствующий BMP.
4. Возвращает список изображений и их пиксельные буферы.

#### `save_layer_mimages(imgs, pix, k, nz, xmin, xmax, ymin, ymax, zmin, zmax, umin, umax, output_dir)`

1. Вызывает `write_header_to_images` — записывает заголовок (параметры сетки и диапазон `u`) в строку `y=0` всех пяти картинок.
2. Сохраняет файлы:
   - имена вида `"{output_dir}/{k+1} (M{m+1}).bmp"`, где:
     - `k+1` — номер слоя по Z,
     - `M1..M5` — номер компоненты нормали.

#### `generate_mimages(F, ..., output_dir)`

Высокоуровневая функция:

1. Создаёт папку `output_dir`.
2. Вызывает `compute_function_field`, чтобы получить сетку и поле `u`.
3. Для каждого слоя `k = 0..nz-1`:
   - вызывает `generate_layer_mimages` для построения картинок;
   - записывает заголовок и сохраняет BMP через `save_layer_mimages`.

Результат — директория с пятью картинками на каждый слой, полностью готовыми для визуализатора.

### `r_functions.py` — булевая алгебра над F(x,y,z)

Модуль реализует **R‑функции** — гладкие аналоги логических операций над неявными функциями:

- Линейные при `alpha = 1`:
  - `r_intersection_alpha1(w1, w2)` — пересечение (аналог `AND`).
  - `r_union_alpha1(w1, w2)` — объединение (аналог `OR`).

- Обобщённые:
  - `r_intersection(w1, w2, alpha=1.0)` — пересечение с параметром сглаживания `alpha`.
  - `r_union(w1, w2, alpha=1.0)` — объединение.

- Инверсия:
  - `r_inversion(w)` — просто `-w` (меняет «внутри» и «снаружи» местами).

- Квадратичные при `alpha = 0` (чаще всего используемые в проекте):
  - `r_intersection_alpha0(w1, w2)`.
  - `r_union_alpha0(w1, w2)`.

Именно эти функции позволяют в `main.py` аккуратно вырезать отверстие под фитиль, формировать углубление и добавлять фитиль‑палочку, оставаясь в рамках одной скалярной функции `F(x,y,z)`.

### `Viz_pyvista.py` — визуализатор M‑образов

Этот файл отвечает за **просмотр результата** генерации M‑образов. Он использует библиотеку PyVista (поверх VTK) для быстрой 3D‑визуализации.

Основные шаги работы:

1. **Чтение заголовка:**
   - Берём один из файлов, например `images/128 (M1).bmp`.
   - Функция `read_header_from_mimage` читает:
     - размеры сетки `nx, ny, nz`;
     - границы `xmin, xmax, ymin, ymax, zmin, zmax`;
     - диапазон `umin, umax`.

2. **Чтение нормалей:**
   - Функция `read_normals_from_mimages(mimage_dir, nx, ny, nz)`:
     - для каждого слоя `k` и для каждого из пяти файлов `M1..M5`:
       - открывает BMP;
       - через `_decode_normals_from_layer` преобразует его в числовой массив нормалей:
         - игнорирует строку `y=0` (заголовок);
         - берёт только столбцы `0..nx-2` (внутри ячеек).
     - собирает четырёхмерный массив `normals[k, i, j, m]` — компоненты `n1..n5` для каждой ячейки.

3. **Построение облака точек:**
   - Функция `build_point_cloud_from_normals(normals, header, magnitude_threshold, downsample_factor)`:
     - вычисляет координаты центров ячеек по параметрам из заголовка;
     - берёт вектор `gradients = normals[..., :3]` — первые три компоненты нормали;
     - считает длину нормали в 3D и отбрасывает ячейки, где она мала (`magnitude_threshold`);
     - на оставшихся ячейках формирует точки:
       - координаты центра ячейки `(x, y, z)`;
       - нормаль в этой точке.
     - при необходимости прореживает сетку (`downsample_factor`), чтобы ускорить отрисовку.

4. **Визуализация через PyVista:**
   - Функция `visualize_with_pyvista(points, normals, ...)`:
     - создаёт объект `PolyData` из массива точек;
     - добавляет в него атрибуты нормалей и координату `Z` как скаляр для окраски;
     - через `plotter.add_mesh` рисует облако точек (точки можно отображать как маленькие сферы);
     - опционально добавляет стрелки нормалей (`add_arrows`) для подмножества точек;
     - настраивает камеру (`iso`), оси, цветовую шкалу и текст в углу;
     - открывает интерактивное окно, где можно вращать/масштабировать сцену.

5. **Точка входа:**

```bash
python Viz_pyvista.py
```

Скрипт:
  - читает `images/128 (M1).bmp`,
  - сообщает параметры заголовка,
  - строит облако точек и открывает окно PyVista.

## Алгоритм «от F(x,y,z) до картинки»

Соберём всё вместе в виде последовательных шагов.

1. **Выбор фигуры и области:**
   - В `main.py` выбираем функцию `F(x,y,z)` (например, `candle`) и задаём границы объёма `xmin..xmax`, `ymin..ymax`, `zmin..zmax` и размеры сетки `nx, ny, nz`.

2. **Запуск генерации:**
   - Вызов `start(candle)` приводит к тому, что для `F = candle` вызывается:
     ```python
     generate_mimages(F, xmin, xmax, ymin, ymax, zmin, zmax, nx, ny, nz, output_dir)
     ```

3. **Вычисление поля F и диапазона значений:**
   - `compute_function_field` строит 3D‑сетку и заполняет её значениями `u = F(x,y,z)`, одновременно вычисляя `UMIN` и `UMAX`.

4. **Расчёт нормалей и формирование палитр:**
   - Для каждого слоя `k`:
     - функция `generate_layer_mimages`:
       - обходит все ячейки;
       - находит те, где F меняет знак (ячейка пересекает поверхность F=0);
       - для таких ячеек считает нормали `n1..n5` и нормирует их;
       - заполняет пять M‑образов закодированными значениями компонент нормали.

5. **Запись заголовков и сохранение файлов:**
   - `save_layer_mimages`:
     - в строку `y=0` каждого из пяти изображений записывает параметры сетки и диапазон `F`;
     - сохраняет BMP‑файлы c правильными именами.

6. **Визуализация:**
   - `Viz_pyvista.py`:
     - по одному из файлов читает заголовок и понимает, как устроен объём;
     - читает все M‑образы и восстанавливает нормали в каждой ячейке;
     - по ненулевым нормалям строит облако точек поверхности;
     - показывает результат пользователю в интерактивном окне.

Таким образом, весь путь выглядит так:

```text
F(x,y,z) в main.py
    ↓
compute_function_field → поле u[k][i][j]
    ↓
generate_layer_mimages → нормали n1..n5 в M1..M5
    ↓
save_layer_mimages → BMP‑файлы с заголовком
    ↓
Viz_pyvista.py → чтение нормалей → облако точек → интерактивное окно
```

Этот документ можно использовать как точку входа для понимания проекта и как «дорожную карту» при добавлении новых фигур или альтернативных визуализаторов.
